Projeto desenvolvido durante o curso **Networking Basics** da **Cisco Networking Academy**. O objetivo é consolidar os fundamentos teóricos de Redes de Computadores, documentar os laboratórios práticos realizados no Cisco Packet Tracer e aplicar boas práticas de documentação técnica com Git e GitHub.

---

## 🎯 Objetivos do Projeto

- **Consolidação Teórica:** Mapear e estruturar os conceitos fundamentais de arquitetura, camadas e protocolos de rede.
- **Prática Hands-On:** Documentar o passo a passo, topologias e testes dos 12 laboratórios práticos do Packet Tracer.
- **Portfólio Técnico:** Apresentar a evolução em administração de redes, troubleshooting e documentação legível em Markdown.
